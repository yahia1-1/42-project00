# Project 00 - Linux & Git Fundamentals

## About

This project helped me learn the basics of Linux and Git.

## What I Learned

- Navigate directories using `cd` and `pwd`
- Create directories using `mkdir`
- Create and manage files
- Use basic Git commands
- Create commits
- Push a project to GitHub

## Git Workflow

The basic Git workflow I learned is:

1. Edit files
2. `git add`
3. `git commit`
4. `git push`

## Why Git Makes Development Easier

Git makes development easier because it tracks changes in my project and keeps a history of my work.

It also helps me organize my changes and upload my project to GitHub.
